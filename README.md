# 🧮 Mini Calculatrice en C (CLI)

Une petite calculatrice en ligne de commande écrite en C.  
Elle permet d’effectuer les opérations mathématiques de base et quelques fonctions avancées.

---

## ✨ Fonctionnalités
- Addition (**+**)  
- Soustraction (**-**)  
- Multiplication (**×**)  
- Division (**÷**)  
- Puissance (**^**)  
- Modulo (**%**)  
- Factorielle (**!**)  
- Racine carrée (**Sqrt**)
